# 💫 About Me:
Desarrollador Full-Stack & Mobile (Bilingüe) con sólida experiencia en arquitectura<br>de software escalable, sistemas offline-first(Flutter/Dart con BLoC) y ecosistemas<br>web de alto rendimiento (React/TypeScript, Node.js/Python).<br>Especializado en metodologías ágiles Scrum, liderando el ciclo de vida completo<br>del desarrollo (SDLC) bajo esquemas de sprints iterativos, estimación de historias<br>de usuario, planificación de releases y entrega continua de valor. Apasionado por<br>la ingeniería de sistemas aplicada, la automatización con IA (RAG/Embeddings) y la<br>gestión de infraestructura propia (Linux/Docker/Cloudflare). Capacidad<br>comprobada para conceptualizar, estructurar y desplegar soluciones robustas<br>desde el código hasta producción con altos estándares de calidad.<br>
